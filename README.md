> Named after the camel with two humps because of the two backends 🐫
# Bactrian
An optimising native compiler for a subset of OCaml, written in OCaml with an LLVM backend for real hardware and a backend for a toy ISA (named camel) designed for Bactrian. 
> **Status:** early development.
## Roadmap of Development
- [ ] Front end and reference interpreter
- [ ] IRs and LLVM path, working end to end
- [ ] Custom ISA and emulator
- [ ] Native backend
- [ ] Optimiser
- [ ] Precise GC and differential fuzzing
- [ ] Results and write-up
